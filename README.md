# Python Coach Course (AI-Driven, Self-Paced)

This repo is a small, test-driven Python refresh course designed to be run with a CLI AI coach (OpenCode-style).

You write the code in each exercise's `solution.py`.
The coach AI creates prompts/tests and tracks progress in `progress.json`.

Start here:

1. **`LEARNER_GUIDE.md`** — how to learn (the basic loop, the gate, the bug-log rule).
2. **`COACH.md`** — the full contract, if you want the deep detail.
3. **`STRUCTURE.md`** — the file layout, if you want to know why a file exists.
