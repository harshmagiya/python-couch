# Review Rubric (Coach-Used)

Keep reviews short and consistent. Prefer 1-2 high-impact improvements.

Checklist:

1) Correctness: handles required cases, no hidden assumptions.
2) Edge cases: empty input, whitespace, negative numbers, ties, etc.
3) Clarity: names reflect intent; minimal cleverness.
4) Structure: small functions; limited nesting; early returns.
5) Data modeling: pick the simplest type that fits.
6) Pythonic usage: use built-ins appropriately (but not at the cost of readability).
7) Testing mindset: can we add a test to prevent regressions?

Coach constraint:

- During debugging/review, do not provide the final solution or directly patch learner code unless explicitly requested.
